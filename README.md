# وب‌سایت مهندس افشین رحمانی

وب‌سایت فارسی و راست‌به‌چپ برای معرفی خدمات تخصصی گیاهپزشکی مهندس افشین رحمانی، کارشناس ارشد گیاهپزشکی و مشاور کود، سم و بذر در قزوین، زنجان، البرز و تهران.

این پروژه بر اساس فایل `complete-website-clone-development.zip` شاخهٔ `main` استخراج و توسعه داده شده است. ساختار صفحه، صحنهٔ سه‌بعدی چمن، حرکت دوربین، باد، مه و کنترل‌های تعاملی نسخهٔ مرجع حفظ شده‌اند.

## امکانات

- طراحی کاملاً فارسی، RTL و واکنش‌گرا برای موبایل و دسکتاپ
- پس‌زمینهٔ سه‌بعدی تعاملی با Three.js و هفت مرحلهٔ حرکت دوربین
- معرفی خدمات آفات‌شناسی، بیماری‌شناسی، کود، سم، بذر و پایش مزرعه
- گالری شش‌تصویری با دسته‌بندی و lightbox
- شش مقالهٔ کامل فارسی با پنجرهٔ مطالعه
- فرم درخواست با اعتبارسنجی شمارهٔ تماس و ایمیل
- فونت‌ها، آیکون‌ها و تصاویر به‌صورت محلی؛ بدون وابستگی به سرویس تصویر سایت مرجع
- متادیتای فارسی و دادهٔ ساختاریافتهٔ Schema.org برای موتورهای جست‌وجو

## اجرا

```bash
npm install
npm run dev
```

برای بررسی نهایی:

```bash
npm run typecheck
npm run build
npm run preview
```

## نکتهٔ فرم درخواست

در نسخهٔ فعلی، درخواست‌ها فقط در `localStorage` مرورگر کاربر با کلید `afshin-consultation-requests` ذخیره می‌شوند و به هیچ سرویس بیرونی ارسال نمی‌شوند. برای استفادهٔ عملیاتی، تابع `handleSubmit` در `src/SiteSections.tsx` باید به API، ایمیل یا سامانهٔ پیامک مالک سایت متصل شود.

## ساختار اصلی

- `src/GrassComponents.tsx`: صحنهٔ سه‌بعدی، کنترل‌های مزرعه و گالری
- `src/SiteSections.tsx`: تمام بخش‌ها، مقالات و فرم
- `src/App.tsx`: چیدمان کلی و اسکرول
- `src/index.css`: فونت‌ها، رنگ‌ها و تنظیمات RTL
- `public/images/`: تصاویر محلی بهینه‌شدهٔ WebP
- `ASSETS.md`: منابع تصاویر
