# وب‌سایت مهندس افشین رحمانی

وب‌سایت چهارزبانه برای معرفی خدمات تخصصی گیاهپزشکی مهندس افشین رحمانی، کارشناس ارشد گیاهپزشکی و مشاور کود، سم و بذر در قزوین، زنجان، البرز و تهران.

این پروژه بر اساس فایل `complete-website-clone-development.zip` شاخهٔ `main` استخراج و توسعه داده شده است. ساختار صفحه، صحنهٔ سه‌بعدی چمن، حرکت دوربین، باد، مه و کنترل‌های تعاملی نسخهٔ مرجع حفظ شده‌اند.

## امکانات

- چهار زبان کامل: **فارسی، العربية، Türkçe و English**
- چیدمان RTL برای فارسی و عربی و LTR برای ترکی و انگلیسی
- انتخاب خودکار زبان بر اساس مرورگر و ذخیرهٔ انتخاب کاربر در `localStorage`
- فونت Noto Naskh/Vazirmatn برای فارسی و عربی و Fraunces/Inter برای ترکی و انگلیسی
- پس‌زمینهٔ سه‌بعدی تعاملی با Three.js و هفت مرحلهٔ حرکت دوربین
- معرفی خدمات آفات‌شناسی، بیماری‌شناسی، کود، سم، بذر و پایش مزرعه
- گالری شش‌تصویری با دسته‌بندی و lightbox
- شش مقالهٔ کامل در هر زبان با پنجرهٔ مطالعه
- فرم درخواست با اعتبارسنجی شمارهٔ تماس و ایمیل
- فونت‌ها، آیکون‌ها و تصاویر به‌صورت محلی؛ بدون وابستگی به سرویس تصویر سایت مرجع
- متادیتا و جهت صفحه به‌هنگام‌رسانی می‌شوند و نیازی به reload برای تغییر زبان نیست

## اجرا

```bash
npm install
npm run dev
```

برای بررسی نهایی:

```bash
npm run typecheck
npm run build
npm run preview
```

## انتشار با GitHub Pages

Workflow آماده در `.github/workflows/deploy.yml` با هر push روی `main` و همچنین به‌صورت دستی از تب **Actions** اجرا می‌شود.

1. تغییرات را به شاخهٔ `main` منتقل کنید.
2. در تنظیمات مخزن، مسیر **Settings → Pages → Build and deployment** را باز کنید و **Source** را روی **GitHub Actions** قرار دهید. این کار فقط یک‌بار لازم است.
3. Workflow با نام **Deploy website to GitHub Pages** را اجرا کنید یا منتظر اجرای خودکار آن بعد از push بمانید.

نشانی پیش‌فرض سایت:

**https://rahmaniho.github.io/afshin/**

مقدار `base: './'` در Vite و مسیرهای نسبی تصاویر باعث می‌شوند سایت در زیرمسیر `/afshin/` نیز بدون خطای asset اجرا شود. فایل `.nojekyll` نیز هنگام build در خروجی قرار می‌گیرد.

## نکتهٔ فرم درخواست

در نسخهٔ فعلی، درخواست‌ها فقط در `localStorage` مرورگر کاربر با کلید `afshin-consultation-requests` ذخیره می‌شوند و به هیچ سرویس بیرونی ارسال نمی‌شوند. زبان انتخاب‌شده نیز با کلید `afshin-language` ذخیره می‌شود. برای استفادهٔ عملیاتی فرم، تابع `handleSubmit` در `src/SiteSections.tsx` باید به API، ایمیل یا سامانهٔ پیامک مالک سایت متصل شود.

## ساختار اصلی

- `src/GrassComponents.tsx`: صحنهٔ سه‌بعدی و شیدرهای مرجع
- `src/GrassInteractions.tsx`: کنترل‌های مزرعه، گالری و lightbox چندزبانه
- `src/SiteSections.tsx`: تمام بخش‌ها، مقالات و فرم
- `src/i18n/`: Provider و منابع کامل فارسی، عربی، ترکی و انگلیسی
- `src/App.tsx`: چیدمان کلی و اسکرول
- `src/index.css`: فونت‌ها، رنگ‌ها و تنظیمات دوطرفهٔ RTL/LTR
- `.github/workflows/deploy.yml`: ساخت و انتشار خودکار GitHub Pages
- `public/images/`: تصاویر محلی بهینه‌شدهٔ WebP
- `ASSETS.md`: منابع تصاویر
